Spendline provides AI cost controls for B2B software companies, allowing businesses to set budgets, monitor AI usage per customer, and prevent overspending. The platform routes supported AI requests, records attributed costs, and applies configurable controls to ensure AI spend stays within defined limits. It offers integration guides, dashboards, and detailed reporting to help finance and engineering teams manage AI budgets effectively.

**Areas:** AI · FinOps · B2B · CostManagement · SaaS

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for Spendline: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
